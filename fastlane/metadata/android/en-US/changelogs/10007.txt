YuTbe v1.0.7

Faster
- Downloads: fixed a bug that split every file under ~67 MB into 128 tiny requests. Files are now downloaded in 512 KB pieces, using far fewer connections.
- Faster app start and first video: a Baseline Profile now pre-compiles YuTbe's code when the app is installed.
- Large messages from YouTube pages (playlists) are processed in the background, so the page no longer stutters.

Smaller and lighter
- Expired video data is now deleted automatically. Earlier versions kept about 100 KB of it per video played; that leftover data is removed once after updating.
- The APK no longer includes Intel (x86_64) code, which phones do not use.
- The cookie cache can no longer grow without limit during long sessions.
- Page console messages are no longer logged in release builds.

More reliable
- Subtitle and thumbnail downloads now time out instead of hanging, and can be cancelled.
- Two downloads at the same time no longer change each other's connection count.
- One consistent browser identity (the phone's current Chrome version) for the page, the player and the extractor.
- Screens opened from YouTube pages can no longer crash the app when no Activity is available.

Clean-up
- Removed unused code and texts (old restart dialog, an unused build file, an unused import).
- Small internal tidy-ups (shared constants, faster checksum code, clearer naming).

Note: paused downloads from older versions restart from the beginning after updating.
